# Secure Login System

## Description

A secure web application that allows users to register and log in safely using hashed passwords. The application demonstrates secure authentication practices including password hashing, SQL injection protection, session management, and logout functionality.

## Features

- User Registration
- Secure Login
- Password Hashing using bcrypt
- SQLite Database
- SQL Injection Protection using Parameterized Queries
- Session Management
- Logout

## Technologies

- Python
- Flask
- SQLite
- bcrypt
- HTML
- CSS

## Run

```bash
python app.py
```

Then open:

```
http://127.0.0.1:5000
```
